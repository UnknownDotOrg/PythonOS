Hi! Thanks for using PythonOS!
Read this if it's your first time using PythonOS.

1. Set up
---------------
First, you need to check if Python is installed on your machine.
If not, you can download it here : https://www.python.org/

(Python is already installed on most Linux distributions.)

You can check that Python is installed by running the command : 

python3 --version

Then, you can go on to the next step.
---------------

2. Running PythonOS
-------------------
When you have Python installed, open a terminal, and type the following command :

python3 main.py

After that, PythonOS will be running.
